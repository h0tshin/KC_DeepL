# KC DeepL for PopClip

Send selected text from PopClip to KC DeepL's text translation workspace.

## Install

1. Build and launch KC DeepL at least once so macOS registers its `kcdeepl` URL scheme.
2. Double-click `KCDeepL.popclipext`.
3. Approve the extension in PopClip if prompted.

## Use

Select text in any app and click the KC DeepL icon in the PopClip bar. KC DeepL
will open with the selected text. If automatic translation is enabled in KC
DeepL, translation starts automatically.

The extension uses PopClip's native Open URL action and contains no executable
shell or AppleScript code.
