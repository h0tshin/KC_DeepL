# KC DeepL Product Requirements

## 1. 목표

KC DeepL은 macOS에서 어디서든 빠르게 텍스트를 번역하는 즉석 번역 앱이다. DeepL 데스크톱 앱의 핵심 패턴인 선택 텍스트 단축키, 2패널 번역 화면, 파일 번역, 번역 기록, 글쓰기 보정, 화면 캡처 번역 흐름을 참고하되, 기본 번역 모델은 Gemini API 기반으로 시작한다.

## 2. 초기 릴리스 범위

### 포함

- macOS SwiftUI 앱 목업
- 메인 번역 화면: 원문 입력, 언어 선택, 번역 결과, 번역 실행
- 오른쪽 도구 패널: 격식/비격식, 스타일 프로필, 용어집, 스타일 규칙, 최근 기록
- 설정 창: 일반, 키보드 단축키, 손쉬운 사용, 파일 및 번역, 고급
- 고급 설정: LLM 공급자, API 키, 세부 모델, 자동 번역, temperature
- 기본 LLM 설정: Gemini / `gemini-2.5-flash-lite`
- 화면 캡처 진입: 캡처 선택 목업과 입력 영역 첨부
- PDF 파일 번역: 페이지 문맥/위치 보존, 디지털 텍스트와 Vision OCR, 원본 구조를 보존하는 번역 레이어 출력
- 파일 번역 엔진: Apple 내장 번역, Codex App Server, API 키와 모델을 선택하는 Gemini API
- 번역 기록의 파일 저장과 설정 토글
- SwiftPM 빌드/실행 스크립트와 Codex Run 액션

### 제외 또는 다음 단계

- 전역 단축키 등록과 선택 텍스트 읽기
- 화면 캡처 결과의 실제 OCR 텍스트 인식
- 시스템 로그인 아이템 등록
- 앱별 단축키 차단의 실제 프로세스 감지

## 3. 사용자 시나리오

1. 사용자는 앱을 열고 왼쪽 입력 패널에 텍스트를 붙여넣는다.
2. 앱은 원문 언어를 자동 감지하거나 사용자가 직접 고른다.
3. 사용자는 대상 언어를 선택하고 원문을 입력한다.
4. 앱은 입력이 1초 이상 멈추면 Gemini `gemini-2.5-flash-lite`로 번역을 요청하고 오른쪽 패널에 결과를 표시한다.
5. 사용자는 오른쪽 도구 패널에서 용어집/스타일 설정 진입점을 확인한다.
6. 사용자는 햄버거 메뉴에서 설정을 열고 모델 공급자와 API 키를 바꿀 수 있다.
7. 사용자는 화면 캡처 버튼으로 캡처 흐름에 진입한다. 초기 릴리스에서는 캡처 상태와 입력 첨부까지만 제공한다.
8. 사용자는 파일 번역에서 PDF를 선택하고 Apple, Codex 또는 Gemini API 엔진과 모델을 고른다.
9. 앱은 페이지별 텍스트와 좌표를 수집하고, 페이지 전체 문맥을 ID가 지정된 블록으로 번역한 뒤 원본 위치에 번역 레이어를 배치한다.
10. 사용자는 원본/번역본을 미리 보고 원본과 다른 이름으로 저장된 PDF를 연다.

## 5. 비기능 요구사항

- macOS 14 이상에서 실행한다.
- Apple 내장 파일 번역은 Translation 프레임워크가 있는 macOS 15 이상에서만 활성화하고, macOS 14에서는 Codex 또는 Gemini API 경로를 제공한다.
- SwiftUI 우선으로 구현하고, 실제 전역 단축키/OCR/권한 처리가 필요해지는 단계에서만 AppKit 또는 Vision 연동을 추가한다.
- 자동 번역이 켜져 있으면 사용자가 입력하거나 붙여넣은 텍스트를 1초 디바운스 후 외부 API로 전송한다. 자동 번역을 끄면 번역 버튼을 실행할 때만 전송한다.
- 번역 실패 시 원인을 UI에 표시한다.
- 원본 PDF는 수정하거나 덮어쓰지 않는다. 전자 서명, 잠금, 변경 금지 문서는 처리하지 않는다.
- 앱의 라틴 UI/본문은 Barlow, 한글은 Noto Sans KR, 고정폭 텍스트는 D2Coding을 우선한다. 폰트는 정적 파일과 라이선스를 앱에 포함해 프로세스 범위로 등록하고 실패 시 시스템 글꼴로 대체한다.
- PDF 페이지 수·media/crop/bleed/trim/art box·회전·기존 일반 주석·링크 URL/action이 출력에서도 유지되는지 저장 직후 구조적으로 재검증한다. 기존 주석의 appearance stream 존재 여부와 번역 overlay의 bounds, 마스크/글자 색, 정렬, 글꼴/glyph, 표시/인쇄 속성도 확인한다. 번역 영역과 겹치는 지원 URL action은 overlay에도 복제하고 사용자에게 확인 경고를 표시한다. 입력형 PDF 양식은 appearance 손상을 방지하기 위해 분석 단계에서 거부한다.
- 번역문 팽창, 대상 문자 글꼴, 복잡하거나 추정 불가능한 배경, 단일 URL로 복제할 수 없는 중첩 링크, Link가 아닌 기존 주석과의 중첩, OCR 신뢰도로 인해 시각적 동일성을 보장할 수 없는 영역은 경고하거나 안전하게 실패한다. 번역 전에 판별 가능한 fatal 조건은 엔진 호출 전 preflight에서 중단한다. 0/90/180/270도와 MediaBox 원점 (0, 0)을 지원 범위로 제한하되 비영점 CropBox는 허용한다. 90°/270°는 동일 문서의 임시 0° 페이지에서 FreeText appearance를 만든 뒤 원래 페이지로 이동하고 최종 appearance를 검증한다. 저장 폴더 쓰기 권한도 엔진 호출 전 probe한다. 원본 content stream을 유지하지만 임의 이미지·표·벡터의 픽셀 동일성을 구조 검사만으로 주장하지 않는다.
- 일반 텍스트/Live 설정의 기존 API 키는 `UserDefaults`로 저장하되 소스에는 기본 API 키를 포함하지 않는다. PDF 내용 전송에 쓰는 파일 번역 API 키는 해당 화면의 메모리에만 유지하고 영구 저장하지 않는다.

## 6. 공식 레퍼런스 반영

- DeepL Mac 앱은 선택 텍스트 번역, 글쓰기 개선, 파일 번역, 기록, 단축키 중심의 데스크톱 UX를 제공한다.
- DeepL 화면 캡처 기능은 캡처 영역 선택 후 OCR로 원문을 추출해 번역한다. 본 초기 구현은 캡처 진입까지만 제공한다.
- Gemini API는 `generateContent` REST 호출과 API key 인증을 사용한다. 기본 모델은 저지연 경량 번역에 적합한 `gemini-2.5-flash-lite`로 둔다.
