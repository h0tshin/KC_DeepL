# KC DeepL UX/UI Design

## 1. 디자인 원칙

- 빠른 번역 앱이므로 첫 화면은 설명 페이지가 아니라 실제 번역 작업 화면이다.
- 다크 테마를 기본으로 하되 macOS 시스템 컨트롤과 접근성을 해치지 않는다.
- DeepL 레퍼런스의 2패널 구조, 상단 모드 바, 오른쪽 도구 패널, 별도 설정 창을 따른다.
- 기능 소개 문구보다 작업 가능한 컨트롤을 우선한다.
- OCR은 다음 단계 기능이므로 현재 UI에서는 캡처 진입과 상태 안내까지만 명확히 표시한다.

## 2. 메인 창 레이아웃

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 텍스트 번역 | DeepL Write | 파일 번역 | 기록              H  ☰     │
├─────────────────────────────────────────────────────────────────────┤
│            언어 감지        ⇄        한국어                  툴바 │
├───────────────────────────────┬─────────────────────────────────────┤
│ 원문 입력                     │ 번역 결과                            │
│                               │                                     │
│ 파일 드롭 영역          캡처 │ 중앙 안내 또는 번역문                  │
│ 번역 버튼                     │                                     │
├───────────────────────────────┴─────────────────────────────────────┤
│ 보안 상태 / 실행 상태 / 보조 도구 아이콘                              │
└─────────────────────────────────────────────────────────────────────┘
```

## 3. 오른쪽 도구 패널

- 표시 방식: 상단 툴바 버튼으로 토글
- 너비: 약 280pt
- 구성:
  - 편집 도구
  - 격식/비격식
  - 스타일 프로필
  - 용어집
  - 스타일 규칙
  - 최근 기록

## 4. 설정 창

왼쪽 사이드바:

- 일반
- 키보드 단축키
- 손쉬운 사용
- 파일 및 번역
- 고급

오른쪽 상세:

- 첨부 레퍼런스처럼 제목, 설명, 컨트롤을 세로로 정렬한다.
- 섹션 사이에 얇은 구분선을 둔다.
- 고급 탭은 LLM 설정을 먼저 배치하고 차단 목록을 아래에 둔다.

## 5. 화면 캡처 UX

초기 구현:

1. 원문 패널 하단의 점선 캡처 버튼 클릭
2. 캡처 선택 목업 시트 표시
3. 사용자가 캡처 완료를 누르면 원문 필드에 캡처 안내 문구 삽입

추후 구현:

1. 화면 녹화 권한 확인
2. 전체 화면 overlay로 영역 선택
3. Vision OCR 수행
4. 원문 필드 삽입
5. 자동 번역 실행

## 6. 색상과 타이포그래피

- 배경: 어두운 중립 회색
- 강조: macOS system blue
- 성공/보안 상태: system green
- 텍스트: primary/secondary/tertiary semantic foreground
- 입력 힌트: 26-30pt, 번역문: 25pt
- 설정 제목: title3 bold
